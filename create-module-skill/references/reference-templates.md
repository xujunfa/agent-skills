# References 文件模板

## 默认文件与灵活调整

每个模块 skill 的 `references/` 目录默认包含 5 个深度知识文件。**可根据模块特点灵活调整**：

- **可省略**：如果模块没有 debug 工具（无 logger、无 FG），省略 `debug-tooling.md`
- **可新增**：
  - `cross-module-integration.md` — 当跨模块集成是核心痛点时
  - `platform-differences.md` — 当 Mobile/PC 差异是主要复杂度时
  - 其他自定义文件 — 根据模块特点命名
- **调整后必须**同步更新 SKILL.md 的「按需加载指引」表格

## 填充原则

1. **每个文件不超过 200 行**，超出则拆分或精简
2. **代码片段只保留关键字段**，不是全量复制源码
3. **排查路径按可能性排序**，最常见的放最前面
4. **参考实现尽量指向具体的 commit 或 PR**，而非泛泛的文件名
5. **每次填充完一个文件，立即展示给用户确认**
6. **知识质量标准**：每条知识能否在 30 秒内让 Claude 做出正确判断？不能 → 删掉或重写
