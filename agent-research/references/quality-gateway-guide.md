# 质量网关指南

用户粘贴外部 Agent 的结果后，执行三步处理：提取 → 验收 → 输出。

## Step 1: 结构化提取

外部 Agent 的输出格式不可控（长文、markdown、对话式均有可能）。按 Brief 中的研究问题逐项提取：

**提取模板（内部使用，不展示给用户）：**

```yaml
findings:
  - question: "Brief 中的具体研究问题"
    answer: "核心结论（1-3 句，自行总结，不照搬原文）"
    confidence: high | medium | low
    sources:
      - url: "来源链接"
        credibility: "简述可信度（如：官方文档/个人博客/未验证）"
    raw_excerpt: "原始关键段落（保留上下文，供调用方深入查看）"
```

**Confidence 判断标准：**

| 等级 | 条件 |
|------|------|
| high | 有官方文档或权威来源直接佐证 |
| medium | 有社区经验或多个非权威来源交叉印证 |
| low | 仅单一非权威来源，或 Agent 自行推断无引用 |

**提取原则：**
- 答案用自己的话总结，不照搬 Agent 原文
- 如果 Agent 对同一问题给了矛盾信息，标注矛盾点
- 没有来源链接的结论，confidence 最高为 medium
- 保留 raw_excerpt 是为了让调用方能追溯细节

## Step 2: 验收检查

逐项比对 Brief 中的验收标准。

### 验收结果判定

**✅ 全部通过（所有验收标准满足）**

告知用户：
```
研究完成。所有验收标准已满足。
[展示结构化 findings 摘要]
```

**⚠️ 部分缺失（有明确缺口）**

告知用户：
```
以下验收标准尚未满足：
- [ ] {未通过的标准 1}
- [ ] {未通过的标准 2}

已满足的部分：
- [x] {已通过的标准}

我可以为缺失部分生成补充 Brief，或者你可以：
1. 接受当前结果（忽略缺口）
2. 自行补充缺失信息
3. 让我生成补充 Brief
```

**❌ 严重不足（结果质量太低或完全跑偏）**

告知用户：
```
外部 Agent 的结果与研究目标偏差较大：
- {具体问题描述}

建议：
1. 换一个 Agent 重新执行原 Brief
2. 我来调整 Brief 让目标更明确
3. 降低验收标准，接受当前结果
```

### 补充 Brief 规则

当需要生成补充 Brief 时：
- **只覆盖缺失项** — 不重复已满足的部分
- **引用已有结果** — "上一轮已确认 X，但 Y 仍缺失"
- **更聚焦** — 补充 Brief 的问题数通常 ≤ 2 个
- **轮次上限** — 超过 2 轮补充时，建议用户直接补充或调整标准
- 遵循 `brief-generation-guide.md` 的所有生成原则

## Step 3: 结构化输出

### 输出格式

验收通过后，输出简化的结构化结果（sources 简化为 URL 列表；Step 1 中详细的 credibility 信息仅用于内部判断，不传递给调用方）：

```yaml
research_result:
  topic: "研究主题"
  briefs_issued: 2        # 总共生成了几个 Brief
  rounds: 1               # 经过几轮（含补充）
  findings:
    - question: "问题 1"
      answer: "结论"
      confidence: high
      sources: ["url1", "url2"]
    - question: "问题 2"
      answer: "结论"
      confidence: medium
      sources: ["url3"]
  gaps:                    # 已知局限（即使通过验收）
    - "未找到 v4.0 beta 相关信息"
    - "社区经验样本量较小（仅 2 个案例）"
```

### 输出路由

| 入口模式 | 输出处理 |
|----------|----------|
| 协议调用 | 将 research_result 传递给调用方 skill，不落盘 |
| 独立使用 | 展示结果摘要，询问"是否保存到文件？" |

### 多 Brief 结果合并

当发出多个并行 Brief 时，用户可能：
- **逐个粘贴** — 每个结果独立提取，最后合并验收
- **一次性粘贴** — 识别各 Brief 对应的部分，统一提取

合并规则：
- 同一问题在不同 Agent 有不同答案 → 都保留，标注来源差异
- confidence 取所有来源中最高的（多源交叉验证提升可信度）
- gaps 取所有 Brief 的并集
